# Cattlelog Design Skill

Whenever designing UI for Cattlelog, you MUST read and follow the strict guidelines defined in `references/DESIGN.md`.

## Guidelines Overview
- Read `references/DESIGN.md` for the single source of truth on the Cattlelog design system.
- Utilize the defined Cattlelog Blue and Gold color palettes.
- Apply the specified grid system and spacing rules for responsive layouts.
- Follow the accessibility standards (e.g. custom focus rings, ARIA properties).
- Integrate motion guidelines for view transitions and micro-delights.
